# 量测与缺陷检测

## 1. 量测（Metrology）与检测（Inspection）的区别

这两个概念经常被混淆，但在产线上是完全不同的两类工序：

- **量测（Metrology）**：测量具体数值，回答「是多少」。例如膜厚 25.3 nm、线宽 42 nm。
  输出是连续量，可直接与规格比对。
- **检测（Inspection）**：判断有无异常，回答「有没有问题」。例如某区域存在颗粒。
  输出通常是缺陷的数量、位置与分类。

量测是抽检（不能每片每个点都测，太慢），检测可以全检但分辨率与速度受限。
这个区别决定了两类数据在建模时的用法完全不同。

## 2. 常见量测项目

| 量测项目 | 测量对象 | 典型手段 |
| --- | --- | --- |
| 膜厚 | 薄膜厚度 | 椭偏仪、X 射线反射 |
| 关键尺寸 CD | 线宽/孔径 | CD-SEM、散射测量 |
| 套刻 Overlay | 层间对准偏差 | 光学套刻量测 |
| 方块电阻 Rs | 掺杂层导电性 | 四探针 |
| 结深 | 掺杂深度 | 二次离子质谱、扩展电阻 |

## 3. 为什么需要虚拟量测（VM）

真实的量测有两个限制：一是**抽检**，通常只测每批（lot）中的少数几片；
二是**耗时**，某些量测需要数十分钟甚至更久。

这带来一个矛盾：先进工艺控制需要每一片、每一个关键参数的实时反馈，
但实测数据既不够密也不够快。

虚拟量测（Virtual Metrology）的思路是：用**当前批次可得的设备传感器数据**
（温度、压力、功率、气体流量等）去预测**尚未实测的量测值**。
本质是一个回归问题，输出连续量。

工程上的核心约束是**因果顺序**：只能用「量测发生之前就已经采集到的数据」做输入，
否则会造成数据泄漏，模型指标虚高但线上无效。

## 4. 缺陷检测与分类

缺陷检测设备在晶圆表面扫描，输出缺陷的位置与图像。
下一步是缺陷分类（Defect Classification），把缺陷分为颗粒、划伤、针孔、图形缺陷等类别。

缺陷分类的价值在于区分**致命缺陷（killer defect）**与**非致命缺陷**：
一个落在关键区域的颗粒可能导致 die 失效，落在非功能区域则无害。
因此缺陷数据必须与 die 的坐标关联，才能计算缺陷对良率的实际影响。

## 5. WAT / PCM 电性测试

WAT（Wafer Acceptance Test，也常称 PCM）在晶圆级测量专门设计的测试结构，
得到器件电学参数：阈值电压 Vt、饱和电流、导通电阻、击穿电压、漏电流等。

WAT 数据的特殊价值在于它是**工艺与器件性能之间的桥梁**：
工艺参数的偏移不会直接告诉你器件好不好，但 WAT 数据会。
所以工艺异常分析几乎总是围绕 WAT 参数展开。

## 6. 数据对接时的注意点

量测与检测数据在入库建模时，有几个容易踩的坑：

1. **时间戳对齐**：不同设备的时钟可能不同步，必须统一到同一时基，否则会错位。
2. **坐标系统一**：缺陷坐标、die 坐标、wafer 坐标需要在同一坐标系下才对得上。
3. **抽检带来的缺失不是随机的**：量测点的选择往往有工艺原因（例如总是测固定位置），
   因此缺失值不能简单用均值填充。

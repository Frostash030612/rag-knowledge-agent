# 统计过程控制（SPC）

## 1. 控制图的基本原理

SPC（Statistical Process Control）用控制图区分两种波动：

- **普通原因波动（common cause）**：过程固有的随机波动，属于正常范围
- **特殊原因波动（special cause）**：由可归因的异常事件引起，需要干预

控制图的做法是：用历史数据估计过程的均值与标准差，画出中心线（CL）、
上控制限（UCL）与下控制限（LCL，通常取 ±3σ）。
当数据点超限或呈现非随机模式时，判定过程失控（Out of Control, OOC）。

## 2. 关键区别：OOC 与 OOS

这两个概念经常被混用，但判定对象完全不同：

- **OOC（Out of Control）**：针对**过程**。指过程出现了非随机波动，
  但产品未必超规格。OOC 是「过程需要关注」的信号。
- **OOS（Out of Spec）**：针对**产品**。指测量值超出规格上下限
  （USL/LSL），产品判定不合格。

一个过程可以 OOC 而不 OOS（过程在漂，但产品还在规格内——这是预警）；
也可以 OOS 而未必先 OOC（突发的单点异常）。
**做异常分析时，先分清是哪一种，处理路径完全不同。**

另外需要区分 **SPEC 限值与控制限**：SPEC 来自客户/设计要求，是产品的红线；
控制限来自过程自身的历史波动，通常比 SPEC 更严，用于提前预警。

## 3. 常用控制图类型

| 控制图 | 适用数据类型 | 说明 |
| --- | --- | --- |
| X-bar / R 图 | 连续量，分组抽样 | 分别监控均值与极差 |
| X-MR 图 | 连续量，单值 | 用于每批只能测一个点的场景 |
| p 图 / np 图 | 不良率 | 用于良率类数据 |
| c 图 / u 图 | 缺陷数 | 用于单位面积缺陷数 |
| **EWMA 图** | 连续量 | 对小幅持续漂移敏感，适合检测缓慢偏移 |
| **CUSUM 图** | 连续量 | 累积偏差，对小偏移检测能力强 |

EWMA 与 CUSUM 的共同优点是**对小而持续的偏移比常规 Shewhart 控制图更敏感**——
常规控制图擅长发现突变，但对缓慢漂移反应迟钝。

## 4. 非随机模式的判定规则

除了超限，控制图还要看「模式」。经典的判异规则（Western Electric Rules）包括：

1. 单点超出 ±3σ
2. 连续 3 点中有 2 点超出 ±2σ（同侧）
3. 连续 5 点中有 4 点超出 ±1σ（同侧）
4. 连续 8 点在中心线同侧
5. 连续 7 点持续上升或下降（趋势）

这些规则的作用是把「看起来都在控制限内、但模式不随机」的情况识别出来。

## 5. 过程能力指数

- **Cp**：仅考虑规格宽度与过程波动之比，不考虑过程是否居中
- **Cpk**：同时考虑波动与居中程度，是更常用的指标
- **Ppk**：用整体标准差计算，反映实际表现（Cpk 用组内标准差）

Cpk 与良率的关系：在正态假设下，Cpk = 1.0 约对应 99.73% 的合格率，
Cpk = 1.33 约对应 99.99%。但**这个换算依赖正态假设**，
对于本身偏斜的分布（例如缺陷数、颗粒计数）不能直接套用。

## 6. 多重比较与误报率

当同时监控 100 个参数、每个参数都用 ±3σ 判定时，
即使过程完全正常，按单点 0.27% 的误报概率计算，
每轮也会有约 100 × 0.27% ≈ 0.27 个参数误报，一天跑多轮就会积累大量误报。

这就是为什么**变量越多，越需要多变量方法**（如 PCA + T²/SPE），
而不是简单地把单变量控制图并行铺开。

# DRAM 制造基础知识（示例文档 1/3）

## 1. DRAM 的基本结构与工作原理

DRAM（Dynamic Random Access Memory，动态随机存取存储器）的存储单元采用 1T1C 结构，
即一个存取晶体管（access transistor）加一个存储电容（storage capacitor）。
信息以电荷形式存储在电容中：有电荷表示逻辑 1，无电荷表示逻辑 0。

由于电容存在漏电，电荷会随时间衰减，因此 DRAM 必须周期性刷新（refresh）。
这是 DRAM 与 SRAM 最本质的区别：SRAM 用双稳态触发器存储，不需要刷新；
而 NAND Flash 依靠浮栅电荷存储，属于非易失性存储，也不需要刷新。

## 2. 关键工艺参数

| 参数 | 含义 | 典型关注点 |
| --- | --- | --- |
| 特征尺寸 CD | Critical Dimension，关键尺寸 | 线宽均匀性、CD 偏差 |
| 套刻误差 Overlay | 层间对准精度 | 影响接触孔连接良率 |
| 膜厚 Thickness | 薄膜沉积厚度 | 影响电容值与刻蚀选择比 |
| 方块电阻 Rs | 掺杂层导电性 | 反映注入与退火效果 |

其中 CD 均匀性（CDU）直接影响器件阈值电压的一致性，是先进节点最关键的指标之一。

## 3. 前道与后道

前道工序（FEOL, Front End Of Line）指晶体管形成之前的工序，
包括浅沟槽隔离、阱注入、栅极形成等。
后道工序（BEOL, Back End Of Line）指金属互连形成阶段的工序，
包括接触孔、金属层沉积与平坦化。

对于 DRAM 而言，电容形成工序（capacitor module）是良率与难度的核心，
需要在深宽比极高的结构中均匀沉积高介电常数材料。

# 设备报警处理手册（示例文档 2/3）

## 报警码 ALM-1042：腔体压力异常

- 触发条件：腔体压力偏离设定值超过 8% 且持续 3 秒以上
- 可能原因：
  1. 真空泵性能下降或抽气管路堵塞
  2. 压力传感器漂移，需用标准规校准
  3. 进气阀（MFC）响应异常
- 处理步骤：
  1. 暂停当前批次（lot），记录 wafer ID 与当前 step
  2. 检查真空泵电流是否在正常区间
  3. 用标准压力规校验传感器读数与显示值偏差
  4. 偏差超过 2% 则更换传感器；否则检查 MFC 响应时间
  5. 恢复前必须跑一片 monitor wafer 确认

## 报警码 ALM-2087：射频反射功率过高

- 触发条件：反射功率（reflected power）超过入射功率的 25%
- 常见原因：匹配网络失配、电极积碳、射频线缆接头松动
- 处理要点：先做匹配网络自动调谐；若无效，检查电极积碳并安排预防性维护（PM）
- 注意：该报警频繁出现会导致刻蚀速率不稳定，进而造成 CD 偏差

## 报警码 ALM-3310：气体流量偏差

- 触发条件：MFC 实际流量与设定值偏差超过 5%
- 优先检查：MFC 是否需要重新标定、气瓶余量是否充足
- 若多台机台同时出现，应优先排查气体供应系统而非机台本身

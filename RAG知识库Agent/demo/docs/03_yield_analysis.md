# 良率分析与根因定位（示例文档 3/3）

## 1. 良率损失的两大类

良率损失通常分为两类，定位方向完全不同：

1. **随机缺陷导致的良率损失**（random defect yield loss）
   由颗粒污染、针孔、微小划伤等随机事件造成。
   典型特征：失效 die 在 wafer map 上无规律分布。
   改善方向：洁净度管理、设备颗粒监控、减少搬运。

2. **系统性失效**（systematic failure）
   由工艺窗口偏移或设计-工艺交互造成。
   典型特征：失效呈规律图案，如边缘环状（edge ring）、
   中心聚集（center cluster）、条纹状（striation）、
   或与曝光 shot 边界一致的重复图案。
   改善方向：查工艺均匀性、光刻条件、机台差异。

区分这两类是根因分析的第一步，因为它们的排查路径完全不同。

## 2. 常用的根因定位方法

### 2.1 Commonality Analysis（共性分析）

把同一批失效 lot 放在一起，交叉比对它们共用过的资源：
机台（tool）、腔体（chamber）、原料批次、recipe 版本、操作人员。
共性最高的那一项通常就是根因。

### 2.2 Wafer Map 图案分类

把每片晶圆上 die 的 pass/fail 结果画成图，用图像方法分类图案类型。
不同图案对应不同根因，例如：
- 边缘环状 → 通常与刻蚀或沉积的均匀性有关
- shot 级重复图案 → 通常与光刻掩模或曝光条件有关
- 随机散点 → 通常与颗粒污染有关

### 2.3 统计过程控制配合

用控制图（如 EWMA 控制图）监控关键参数是否失控，
结合 WAT 电性参数的偏移方向，缩小可疑工序范围。

## 3. 数据处理的注意事项

分析失效数据时，训练集与测试集的划分必须按时间切分（time-based split）
或按批次/机台分组切分（GroupKFold）。
如果随机切分，同一批次的数据会同时出现在训练集与测试集中，
造成数据泄漏，模型指标虚高但线上无效。

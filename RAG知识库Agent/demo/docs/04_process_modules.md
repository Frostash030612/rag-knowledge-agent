# DRAM 工艺模块概览

## 1. 为什么工艺模块决定器件性能

DRAM 的存储单元是 1T1C（一个存取晶体管加一个存储电容）。器件的电学性能由各工艺模块
共同决定：晶体管的阈值电压 Vt 由栅极结构与掺杂决定；电容的电容值 C 由介电常数与
几何尺寸决定（C = εA/d）；而两者的接触电阻由互连模块决定。

任何一个模块的参数漂移，都会通过电学参数反映出来。这使得「工艺参数 → 器件电学性能」
之间存在可建模的映射关系，也是虚拟量测（VM）能够成立的前提。

## 2. 光刻模块（Litho）

光刻决定图形的关键尺寸（Critical Dimension, CD）与套刻精度（Overlay）。

- 关键指标：CD 均匀性（CDU）、套刻误差、焦点与曝光剂量稳定性
- 常见异常：曝光剂量漂移导致 CD 整体偏移；焦距漂移导致图形边缘粗糙度变差
- 与其他模块的耦合：光刻的 CD 偏差会直接传递到刻蚀，因为刻蚀以光刻胶图形为掩模

套刻误差过大时，接触孔与下层金属之间可能无法有效连接，直接表现为接触电阻偏高或开路。

## 3. 刻蚀模块（Etch）

刻蚀把光刻定义的图形转移到下层材料。分为干法刻蚀（等离子体）与湿法刻蚀。

干法刻蚀的关键参数包括：射频功率（RF power）、腔体压力、气体流量与配比、电极温度。

- 刻蚀速率（Etch Rate）受射频功率与气体配比影响
- 选择比（Selectivity）指目标材料与被掩模材料的刻蚀速率之比，选择比不足会损伤底层
- 刻蚀轮廓（Profile）是否垂直，直接影响后续填充质量

刻蚀是「CD 偏差的重要来源之一」：即使光刻完全稳定，刻蚀速率的漂移也会造成最终 CD 偏移。

## 4. 薄膜沉积模块（Deposition）

分为化学气相沉积（CVD）、物理气相沉积（PVD）与原子层沉积（ALD）。

- ALD 的优势是逐层自限制生长，厚度控制精度可达原子级，适合高深宽比结构
- 深宽比（Aspect Ratio）越高，台阶覆盖率（Step Coverage）越难保证
- 对于 DRAM 电容结构，需要在极高深宽比中均匀沉积高介电常数（high-k）材料

膜厚均匀性会直接影响电容值，进而影响器件的电荷保持能力与刷新特性。

## 5. 化学机械平坦化（CMP）

CMP 通过化学腐蚀与机械研磨的协同作用实现表面平坦化，是多层互连工艺的关键。

- 关键问题：碟形凹陷（Dishing）与侵蚀（Erosion）
- 抛光速率受压力、转速、研磨液（Slurry）配方影响
- 平坦度不足会导致后续光刻的焦深（DOF）不足，图形失真

## 6. 扩散与离子注入

离子注入用于精确控制掺杂浓度与结深。注入后的退火（Anneal）用于激活掺杂原子
并修复晶格损伤。退火温度与时间会同时影响激活率与扩散长度，存在权衡。

## 7. 模块间的耦合关系

需要特别强调的是：工艺模块之间不是独立的。典型耦合路径包括：

- 光刻 CD 偏差 → 刻蚀后 CD 偏差 → 晶体管 Vt 偏移
- 薄膜厚度偏差 → 电容值偏差 → 刷新特性变差
- CMP 平坦度不足 → 光刻焦深不足 → 图形缺陷

因此做根因分析时，不能只看单一模块的数据，必须沿工艺顺序追溯参数传递路径。

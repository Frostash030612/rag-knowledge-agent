# 洁净室与污染控制

## 1. 洁净度等级

洁净室按单位体积空气中悬浮颗粒的数量分级。传统上使用美制标准
（Class 10 / 100 / 1000，指每立方英尺中 ≥0.5 μm 颗粒的数量），
ISO 14644-1 则按 ISO Class 编号（数字越小越洁净）。

| 传统等级 | ISO 等级 | 典型应用 |
| --- | --- | --- |
| Class 1 | ISO 3 | 极紫外光刻等最敏感工序 |
| Class 10 | ISO 4 | 先进光刻 |
| Class 100 | ISO 5 | 一般前道工序 |
| Class 1000 | ISO 6 | 后道与部分封装工序 |

等级越低（越洁净），单位体积允许的颗粒数越少，建设与运行成本呈非线性上升。

## 2. 污染来源与分类

- **颗粒污染（Particle）**：来自人员、设备磨损、材料、化学品的微粒。
  是最常见的缺陷来源。
- **金属污染（Metallic Contamination）**：铁、铜、钠等金属离子扩散进晶圆，
  会形成深能级陷阱，导致漏电流增大、少子寿命下降。
- **有机污染（Organics）**：来自光刻胶残留、塑料件释气、环境有机物。
- **AMC（Airborne Molecular Contamination，气态分子污染）**：
  酸、碱、有机气体，会腐蚀图形或造成光刻胶表面改性。
- **微尘与雾化颗粒**：来自清洗液雾化、去离子水中的颗粒。

## 3. 人员是最主要的污染源

一个穿着普通服装的人静止时每分钟释放约 10 万个颗粒，
行走时可达数百万个。这就是为什么洁净室要求穿专用洁净服、
限制人员数量与走动速度、禁止化妆与佩戴饰品。

洁净服（Bunny Suit）的作用不是保护人，而是**保护产品不被人的颗粒污染**。

## 4. 清洗工艺

主要清洗手段：

- **湿法清洗**：RCA 标准清洗（SC-1 去除颗粒与有机物、SC-2 去除金属离子）、
  稀释氢氟酸（DHF）去除自然氧化层
- **兆声波清洗**：用高频声波产生的微流去除微小颗粒，避免损伤图形
- **干法清洗**：等离子体清洗，用于对水敏感的工序

清洗的关键权衡是**去除能力与图形损伤之间的平衡**：
清洗力度不足则残留缺陷，力度过强则造成图形倒塌
（高深宽比结构在干燥时的毛细力会导致图形倾斜或倒塌）。

## 5. 污染与良率的关系

污染对良率的影响有两种形态：

- **随机缺陷型**：颗粒落在关键区域造成单点失效，在 wafer map 上表现为散点
- **系统性退化型**：金属污染导致漏电流整体升高，表现为 WAT 参数整体偏移

前者靠检测数据统计，后者必须靠电性参数与清洗设备的共性分析才能定位。
区分这两种形态是良率分析的起点。

## 6. 环境监控

洁净室需要持续监控：颗粒计数、温湿度、压差、AMC 浓度。
这些数据本身也是设备异常分析的辅助证据——
当某区域颗粒数同时升高且有良率下降时，两者可以互相印证。
